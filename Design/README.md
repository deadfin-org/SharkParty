# SharkParty logo concept

`sharkparty-logo.svg` is an editable, transparent vector concept. `sharkparty-logo-preview.png` shows it on Deadfin's abyss background (`#060B12`) at 800 × 800 pixels.

The broken violet-to-teal sonar ring and blue-gray shark carry over Deadfin's visual family. The close-cropped snout rises from below, with a single visible eye and an open coral-red mouth with two rows of sharp teeth. This is a review concept; it has not been wired into the Xcode asset catalog.
