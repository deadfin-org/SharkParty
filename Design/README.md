# SharkParty logo concept

`sharkparty-logo.png` is the current source image. `sharkparty-logo-preview.png` has identical bytes and keeps the existing preview link working. Both are the 1254 × 1254 RGBA image the user selected from the chat.

The broken violet-to-teal sonar ring and blue-gray shark carry over Deadfin's visual family. The close-cropped snout rises from below, with a single visible eye and an open coral-red mouth with two rows of sharp teeth. This is a review concept; it has not been wired into the Xcode asset catalog.

There is no faithful editable vector source yet. The earlier hand-drawn SVG was a different interpretation and has been removed from the active design; it remains recoverable in Git commit `57f12e45`. Any future vectorization should be reviewed against the current raster before replacing it.
